# Glosario y cierre editorial

## Glosario

- **Activo:** información, sistema o capacidad que necesita protección.
- **Allowlist:** contrato explícito de valores aceptados; rechaza el resto.
- **Frontera de confianza:** punto donde cambian las garantías sobre datos o actores.
- **Hardening:** reducción deliberada de superficie mediante controles y configuración.
- **Impacto:** consecuencia si una amenaza tiene éxito.
- **Laboratorio autorizado:** entorno propio o con permiso explícito y alcance definido.
- **Mínimo privilegio:** cada identidad recibe solo el acceso imprescindible.
- **Redacción:** sustitución de datos sensibles antes de registrar eventos.
- **STRIDE:** categorías para formular amenazas de diseño.

## Auditoría de cierre

El curso cubre modelado de amenazas, validación, telemetría, hardening e
incidentes con datos sintéticos. Los modelos del crate clasifican riesgos,
validan identificadores, redactan tokens sintéticos y evalúan configuraciones
locales. No usa red, `unsafe`, dependencias externas ni automatización ofensiva.

El contenido continúa en `draft`: una revisión humana debe validar ejemplos,
referencias y límites antes de cualquier publicación.
